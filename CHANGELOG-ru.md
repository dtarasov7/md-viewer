# История изменений

В этом файле документируются значимые изменения Markdown Viewer.

## [1.2.0] - 2026-10-22

### Добавлено

- Прокрутка колёсиком мыши в TUI: по три строки в документе или по три позиции в списке файлов, с ограничением на границах.
- Поддержка прокрутки вниз в Python 3.8/3.9, где `curses` не экспортирует `BUTTON5_PRESSED`.

### Изменено

- Скрипт запуска переименован из `md_viewer.py` в `md-viewer.py`; обновлены команды запуска и загрузка модуля в тестах.

## [1.1.0] - 2026-08-28

### Добавлено

- Поиск в TUI по `F7` и переход по каждому совпадению клавишами `n` / `p`.
- Совместимая с разными terminfo обработка `Home` / `End`, включая сырые escape-последовательности.
- Отладочный режим `--debug` с выводом полученных кодов клавиш в строке состояния.

### Изменено

- TUI стал режимом по умолчанию; HTML-режим запускается с флагом `--html`.

## [1.0.0] - 2026-07-12

### Добавлено

- Браузерный и терминальный интерфейсы для просмотра Markdown-файлов.
- Рендеринг заголовков, абзацев, списков, цитат, кода, ссылок и pipe-таблиц.
- Адаптивная ширина колонок и горизонтальная прокрутка в TUI.
- Интерактивный регистронезависимый поиск текста в TUI с мгновенной подсветкой.
- Переход между строками с совпадениями по клавишам `n` и `p`.
- Поддержка латинской и русской раскладок для TUI-hotkey, включая Caps Lock.
