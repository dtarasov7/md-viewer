# Markdown Viewer

[![Версия](https://img.shields.io/badge/version-1.2.0-blue.svg)](CHANGELOG-ru.md)

`md-viewer.py` - небольшая программа на Python 3.8 для просмотра Markdown-файлов с таблицами. Она использует только стандартную библиотеку Python и умеет работать в двух режимах: через локальную HTML-страницу в браузере и через терминальный TUI.

## Возможности

- просмотр `.md` и `.markdown` файлов;
- автоматический поиск Markdown-файлов в текущем каталоге, если файлы не указаны;
- открытие явно указанного файла из любого каталога, если у текущего пользователя есть право чтения;
- HTML-просмотр через встроенный локальный HTTP-сервер;
- TUI-просмотр через `curses`;
- поддержка pipe-таблиц Markdown с выравниванием колонок;
- адаптивная ширина колонок в TUI;
- горизонтальная прокрутка широких таблиц;
- интерактивный регистронезависимый поиск текста в TUI по `F7` с мгновенной подсветкой и переходом между совпадениями по `n` / `p`;
- базовый рендер заголовков, списков, цитат, ссылок, inline-code и fenced code blocks.

## Требования

- Python 3.8 или новее;
- для TUI-режима нужен терминал с поддержкой `curses`;
- внешние Python-пакеты не требуются.

## Быстрый старт

Запуск TUI для всех Markdown-файлов в текущем каталоге:

```bash
python3 md-viewer.py
```

Запуск для одного файла:

```bash
python3 md-viewer.py RegressionTestPlan-ru.md
```

Если указан ровно один файл, программа сразу откроет его просмотр, а не страницу списка.

## HTML-режим

HTML-режим включается флагом `--html`:

```bash
python3 md-viewer.py --html --host 127.0.0.1 --port 8765
```

Опции:

- `--host HOST` - адрес сервера, по умолчанию `0.0.0.0`;
- `--port PORT` - порт сервера, по умолчанию `8765`;
- `--no-browser` - не открывать браузер автоматически.

Пример без автоматического открытия браузера:

```bash
python3 md-viewer.py --html --no-browser
```

## TUI-режим

Запуск терминального интерфейса (по умолчанию):

```bash
python3 md-viewer.py
```

Запуск TUI сразу для конкретного файла:

```bash
python3 md-viewer.py /path/to/file.md
```

Для диагностики клавиатуры добавьте `--debug`. В строке состояния будут показаны коды нажатых клавиш:

```bash
python3 md-viewer.py --debug /path/to/file.md
```

Примеры вывода: `262:KEY_HOME` для распознанной Home и `27:'\x1b' 91:'[' 72:'H'`, если терминал передаёт escape-последовательность посимвольно.

Клавиши:

- `Enter` - открыть файл из списка;
- `↑` / `↓` или `k` / `j` - перемещение;
- Колёсико мыши - прокрутка документа или перемещение по списку файлов по три строки;
- `PgUp` / `PgDn` - постраничная прокрутка;
- `←` / `→` - горизонтальная прокрутка;
- `Home` / `End` - начало или конец документа;
- `F7` (или `/`) - открыть интерактивный поиск (совпадения обновляются при каждом введённом символе);
- `n` / `p` (латиница или русская раскладка, любой регистр) - следующее / предыдущее совпадение поиска;
- `r` - перечитать файл;
- `b` (`back`) - вернуться к списку файлов;
- `q` - выйти.

## Поддерживаемый Markdown

Программа реализует практический поднабор Markdown:

- заголовки `#` ... `######`;
- абзацы;
- маркированные и нумерованные списки;
- цитаты;
- fenced code blocks;
- inline-code;
- жирный и курсивный текст;
- ссылки;
- pipe-таблицы с разделителем `---`, `:---`, `---:` и `:---:`.

Это не полноценный CommonMark-парсер. Цель программы - простой просмотр файлов с таблицами без установки дополнительных пакетов.

## Проверка

Проверка синтаксиса:

```bash
python3 -m py_compile md-viewer.py
```

Проверка справки CLI:

```bash
./md-viewer.py --help
```
